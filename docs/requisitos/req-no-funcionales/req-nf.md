## Lista de requisitos no funcionales
Usabilidad: El sistema tiene una interfaz intuitiva la cual es fácil de usar y navegar, el usuario es capaz de entender el funcionamiento de los botones sin necesidad de explicaciones


Fiabilidad: El sistema es estable y con código redundante, tiene cero o pocos errores y si los tiene no alteran la experiencia de manera significativa


Portabilidad: El sistema puede ser usado desde cualquier dispositivo movil o computadora sin importar el navegador u OS


Mantenibilidad: El sistema cuenta con herramientas para mantener las bases de datos de forma sencilla y desde la misma página, el código es flexible y permite añadir nuevas funcionalidades
